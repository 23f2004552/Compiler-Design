Behind the Scenes

                
Understand how MiniLang processes your code step-by-step.

            

            

                

                    
01

                    
Lexical Analysis

                    
The Lexer scans your code character by character, grouping them into "Tokens" (like keywords, identifiers, and operators). It's like breaking a sentence into words.

                

                

                    
02

                    
Syntax Analysis

                    
The Parser takes the tokens and arranges them into an AST (Abstract Syntax Tree). It checks if your code follows the grammatical rules of MiniLang.

                

                

                    
03

                    
Semantic Analysis

                    
The Semantic Analyzer ensures your code makes sense. It checks if variables are declared before use and prevents illegal operations.

                

                

                    
04

                    
Code Optimization

                    
The Optimizer makes your code more efficient. For example, Constant Folding evaluates math like `2+2` at compile-time instead of at runtime.

                

                

                    
05

                    
Code Generation

                    
Finally, the Codegen produces Intermediate Code (TAC). This is a simplified version of your code that is ready to be turned into machine instructions.
